gcrun — Cloud Run Sidepanel · Chrome extension v0.3.1

Effective 2026-11-21 · Last updated 2026-11-26

No data collection

English 한국어 Contact / 문의

gcrun is a Chrome side panel for the Google Cloud Run console. It reads the URL of the Cloud Run console page you have open, summarizes that service in the side panel, and talks only to a bridge program running on your own computer (http://127.0.0.1 or http://localhost).

The extension does not collect, transmit, sell, or share any user data. There is no account, no analytics, no telemetry, no advertising, and no external server operated by the developer. Everything the extension knows stays in your browser profile on your device.

1. Single purpose

Show a side panel next to console.cloud.google.com that summarizes the Cloud Run service the user is looking at, and — when the user has installed the local gcrun command-line tool — offer canary rollout, rollback, live watching and fleet checks for that service through the local bridge.

2. What the extension reads

DataWhyWhere it goes
The URL string of browser tabs, e.g. https://console.cloud.google.com/run/detail/asia-northeast3/api?project=my-proj Parse the project, region and service of the Cloud Run page you are on Parsed in the browser; the extracted project / region / service is kept in chrome.storage.session only
The panel's own settings and UI state (bridge address, optional bridge token, auto-refresh toggle, extra project IDs for a fleet check) Remember your settings between openings chrome.storage.local on your device
The bridge's responses (service list, revisions, traffic split, metric snapshots, license status) Render the panel Shown in the panel; not stored anywhere else

Not read, not requested, not stored: page content or DOM of any website, form fields, passwords, cookies, browsing history, GCP OAuth tokens, GCP service-account keys, gcloud configuration, log contents, or the contents of your Cloud Run traffic.

The extension ships no content scripts. It never injects JavaScript into a page and never scrapes the console DOM; it works from the address-bar URL alone.

3. Where data goes

  • Loopback only. Every network request the extension makes goes to the address configured in the panel (default http://127.0.0.1:8787), a program running on the same machine. The extension has no server of its own.
  • No developer server. The developer operates no backend that receives extension data.
  • No third-party services. No analytics, crash reporting, advertising or tracking SDKs are bundled. The package contains no remote code; every script is inside the extension.
  • No sale or sharing. User data is not sold, rented or transferred to anyone, and is not used for advertising, profiling or any purpose unrelated to the single purpose above.

4. Google Cloud credentials

The extension never asks for, reads or stores Google Cloud credentials, and does not call Google Cloud APIs itself. When you use a privileged action (canary, rollback, fleet check) the extension asks the local bridge, and the gcrun CLI performs the API call with the credentials already present on your machine — for example your own gcloud login. Those credentials never pass through the extension.

5. Extension Pro license (optional)

Pro features are unlocked with a license key bought from the payment provider (Polar.sh) and pasted into the panel once.

  • The key is sent to the local bridge — not to the developer, and not by the extension to the provider.
  • The gcrun CLI validates the key with the provider over HTTPS and stores the result in ~/.config/gcrun/license.json on your machine, with a 7-day offline grace period.
  • The panel only displays the status the bridge reports, which may include the email address the provider returned for that license so you can tell which license is active.
  • If you never enter a key, no licensing request is made at all. All CLI/TUI features remain free and the panel's overview works without a key.

6. Retention and deletion

  • chrome.storage.local — kept until you change the setting or remove the extension.
  • chrome.storage.session — memory-backed, cleared when the browser closes.
  • Removing the extension from chrome://extensions deletes both stores.
  • The bridge's license file lives outside the extension at ~/.config/gcrun/; delete it or run gcrun license deactivate to remove that record.

7. Permissions and why they are needed

  • sidePanel — display the extension as a Chrome side panel.
  • tabs — read the URL of tabs so the panel knows which Cloud Run service you have open, and follow you between tabs without a reload. The URL is parsed; the page is never read.
  • storage — save your panel settings and the current console context locally.
  • https://console.cloud.google.com/* — recognise that the current tab is a Cloud Run console route. No script is injected into the console.
  • http://127.0.0.1/*, http://localhost/* — allow the panel to reach the local gcrun bridge.

8. Children

This is a developer tool and is not directed to children under 13.

9. Changes

If this policy changes, the updated text is published at this address with a new effective date. Material changes are noted in the extension's release notes.

이 확장프로그램은 어떤 사용자 데이터도 수집·전송·판매·공유하지 않습니다. 계정도, 분석 도구도, 텔레메트리도, 광고도, 개발자가 운영하는 외부 서버도 없습니다. 확장프로그램이 아는 모든 정보는 사용자 기기의 브라우저 프로필 안에만 남습니다.

1. 단일 목적

console.cloud.google.com 옆에 사이드패널을 띄워 지금 보고 있는 Cloud Run 서비스를 요약하고, 사용자가 로컬 gcrun 명령줄 도구를 설치한 경우 로컬 브릿지를 통해 카나리 배포·롤백·실시간 감시·Fleet 점검을 제공합니다.

2. 확장프로그램이 읽는 것

이 확장프로그램은 콘텐츠 스크립트를 포함하지 않습니다. 어떤 페이지에도 자바스크립트를 주입하지 않고 콘솔 화면을 긁지 않습니다. 주소창의 URL만으로 동작합니다.

3. 데이터가 가는 곳

  • 루프백(로컬)만 사용합니다. 확장프로그램이 보내는 모든 요청은 패널 설정에 입력한 주소(기본값 http://127.0.0.1:8787)로만 향하며, 이는 같은 컴퓨터에서 도는 프로그램입니다. 확장프로그램 자체 서버는 없습니다.
  • 개발자 서버가 없습니다. 확장프로그램 데이터를 받는 개발자 백엔드가 존재하지 않습니다.
  • 제3자 서비스가 없습니다. 분석·오류 수집·광고·추적 SDK를 넣지 않았습니다. 원격 코드를 쓰지 않으며 모든 스크립트는 확장프로그램 패키지 안에 있습니다.
  • 판매·공유하지 않습니다. 사용자 데이터를 판매·대여·이전하지 않고, 광고·프로파일링 등 위 단일 목적과 무관한 용도로 사용하지 않습니다.

4. 구글 클라우드 자격증명

확장프로그램은 구글 클라우드 자격증명을 요구·열람·저장하지 않습니다. 확장프로그램이 직접 구글 클라우드 API를 호출하지도 않습니다. 카나리·롤백·Fleet 점검 같은 작업을 요청하면 로컬 브릿지를 거쳐 gcrun CLI가 사용자 기기에 이미 있는 자격증명(예: 사용자 본인의 gcloud 로그인)으로 API를 호출합니다. 그 자격증명은 확장프로그램을 거치지 않습니다.

5. Extension Pro 라이선스 (선택)

Pro 기능은 결제 대행사(Polar.sh)에서 구매한 라이선스 키를 패널에 한 번 입력하면 열립니다.

  • 입력한 키는 로컬 브릿지로만 전달되며, 확장프로그램이 개발자나 결제 대행사로 직접 보내지 않습니다.
  • gcrun CLI가 HTTPS로 결제 대행사에 키를 검증하고, 결과를 사용자 기기의 ~/.config/gcrun/license.json에 저장합니다(오프라인 7일 유예).
  • 패널은 브릿지가 알려준 상태만 표시하며, 어떤 라이선스가 활성인지 알 수 있도록 결제 대행사가 반환한 이메일 주소가 함께 표시될 수 있습니다.
  • 키를 입력하지 않으면 라이선스 요청 자체가 발생하지 않습니다. CLI/TUI 기능은 전부 무료이고, 패널의 개요 화면도 키 없이 동작합니다.

6. 보관과 삭제

  • chrome.storage.local — 설정을 바꾸거나 확장프로그램을 제거할 때까지 유지됩니다.
  • chrome.storage.session — 메모리 기반이며 브라우저를 닫으면 지워집니다.
  • chrome://extensions에서 확장프로그램을 제거하면 두 저장소가 모두 삭제됩니다.
  • 브릿지의 라이선스 파일은 확장프로그램 밖 ~/.config/gcrun/에 있으며, 이 파일을 지우거나 gcrun license deactivate를 실행하면 로컬 라이선스 기록이 삭제됩니다.

7. 권한과 사유

  • sidePanel — 확장프로그램을 크롬 사이드패널로 표시하기 위해.
  • tabs — 지금 열려 있는 Cloud Run 서비스를 알기 위해 탭의 URL을 읽고, 탭을 옮겨도 패널을 다시 불러오지 않기 위해. URL만 파싱하며 페이지 내용은 읽지 않습니다.
  • storage — 패널 설정과 현재 콘솔 컨텍스트를 기기에 저장하기 위해.
  • https://console.cloud.google.com/* — 현재 탭이 Cloud Run 콘솔 경로인지 확인하기 위해. 콘솔 화면에 스크립트를 주입하지 않습니다.
  • http://127.0.0.1/*, http://localhost/* — 로컬 gcrun 브릿지에 접근하기 위해.

8. 아동

이 확장프로그램은 개발자 도구이며 만 13세 미만 아동을 대상으로 하지 않습니다.
