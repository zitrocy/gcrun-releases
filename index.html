Canary, rollback and watch for Cloud Run — right next to the console.

gcrun is a command-line tool and TUI for Google Cloud Run. A Chrome side panel adds one-click canary rollout with automatic rollback, live 5xx and instance watching, and a fleet view across projects — all from the console tab you already have open.

Get Extension Pro Install the free CLI

No account, no analytics, no server of ours. Every request the extension makes goes to 127.0.0.1 on your own machine.

Install

1. CLI and TUI (free, forever)

# macOS / Linux — pick the build for your platform from the releases page
curl -L -o gcrun https://github.com/zitrocy/gcrun-releases/releases/latest/download/gcrun-linux-amd64
chmod +x gcrun && sudo mv gcrun /usr/local/bin/

# check it
gcrun --version
gcrun tui              # services, revisions, logs, traffic — your existing gcloud login
gcrun serve            # local bridge the Chrome side panel talks to (127.0.0.1:8787)

ARM builds and macOS binaries are on the releases page. Auth uses the credentials already on your machine (gcloud auth login or a service account).

2. Chrome side panel

Install gcrun — Cloud Run Sidepanel from the Chrome Web Store, open any console.cloud.google.com/run/… tab, and open the side panel. See the privacy policy for exactly what it reads.

The Chrome Web Store listing is not published yet. Until it is, download gcrun-chrome-extension.zip from the latest release, unzip it, and load it from chrome://extensions (Developer mode → Load unpacked).

3. What stays free

  • The whole CLI and TUI: services, revisions, YAML, logs, metrics, traffic split, manual rollback
  • gcrun canary, gcrun watch, gcrun advisor in the terminal
  • The local bridge and the panel's read-only overview

Extension Pro

Pro unlocks the browser side. You buy a license key, paste it into the panel once, and the local bridge validates it with Polar. The key never reaches us; the bridge stores only the validation result on your machine, with a 7-day offline grace period.

One-click canary

Step the traffic 10% → 30% → 100% with a 5xx and latency budget guard, and let it roll back automatically when the new revision misbehaves. A dry run rehearses the sequence without moving a single request.

Watch panel

Live 5xx rate and instance count for the service in the current tab, with webhook alerts on the thresholds you set.

Fleet view

Every project and region you add, in one table — revisions, traffic and recent error spikes.

Report export

Export the fleet and advisor report as Markdown or JSON for an incident write-up or a handover.

Why it is local-only

The extension has no backend. It reads the URL of the console tab, asks the bridge on 127.0.0.1:8787 for the facts, and draws them. Your gcloud credentials stay where they are: the CLI makes the API calls. Nothing about your projects leaves the machine.
